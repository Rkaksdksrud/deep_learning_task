# Task 1 모델 디자인 로드맵

작성: 2026-11-10. 향후 실험을 위한 계획이며 추가 학습은 실행하지 않았습니다.
상세 계획: https://app.notion.com/p/414f1bb35cd4813a97f6db7364307d95 (개인 Notion 접근 권한 필요).

1. 현재 기준 모델과 데이터 분할을 고정하고 원본 결과를 보존합니다.
2. 같은 [32] DNN에서 정규화 3종 × 의미 기반 파생비율 사용 여부 6개 조합을 비교합니다.
3. 전처리를 고정하고 [32], [64], [64,32] × ReLU/GELU를 비교합니다.
4. 상위 구조에서 학습률·dropout·weight decay·batch size를 제한된 후보로 미세 조정합니다.
5. 최종 후보 2개를 동일한 데이터 분할과 사전에 정한 초기화 seed 3개로 비교합니다.
6. 설정을 확정한 다음 전체 데이터로 DNN 하나를 재학습하고 제출물을 검증합니다.

현재 상위 세 설정의 CV 평균 차이는 0.00061 미만이므로 구조의 우열을 단정하지 않습니다.
seed별·fold별 변동까지 확인하고 비슷하면 단순한 구조를 선택합니다. 예측 평균은 사용하지 않습니다.
holdout을 반복해서 최대화하지 않으며 전처리 통계는 각 fold의 학습 부분에서만 계산합니다.
이미 본 holdout을 새 독립 평가처럼 설명하지 않습니다.

다음 코드 개선: 고정 설정 입력, split seed와 모델 초기화 seed 분리, 탐색과 최종 평가 분리.
현재 --seed를 바꾸면 데이터 분할도 달라지므로 그대로 안정성 실험을 해서는 안 됩니다.
새 탐색은 기존 최종 모델 폴더를 덮어쓰지 않고 별도 버전으로 저장합니다.
